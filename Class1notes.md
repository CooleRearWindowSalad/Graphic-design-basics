# 1. Een nieuw document maken

## Documentinstellingen

Bij het maken van een nieuw document kun je verschillende templates gebruiken.

| Instelling      | Waarde                          |
| --------------- | ------------------------------- |
| Width (breedte) | 200 px                          |
| Height (hoogte) | 200 px                          |
| Orientation     | Maakt niet uit                  |
| Artboards       | 1, tenzij je er meer nodig hebt |
| Web             | 72 PPI                          |
| Print           | 300 PPI                         |
| Newspapers      | 250 PPI                         |
| Background      | Transparent                     |

Klik op **Create** om het document te maken.

## Workspace instellen

Ga naar:

**Window → Workspace → Essentials Classic**

Stel Essentials Classic in als je workspace, zodat je met dezelfde interface als tijdens de les werkt.

# 2. De vogel tekenen (Bird)

Voor deze oefening gebruik je het bestand `bird.png` uit de gedownloade ZIP-map.

Het doel is om de vogel na te tekenen met verschillende vormen in Illustrator.

## Stap 1: De afbeelding plaatsen

1. Maak een nieuw document en klik op Create.
2. Ga naar **File → Place**.
3. Open de map waarin je de ZIP-bestanden hebt uitgepakt.
4. Selecteer `bird.png`.
5. Kies onderaan voor Template als je de afbeelding als referentie wilt gebruiken.
6. Klik op Place.

De afbeelding wordt nu als template geplaatst, zodat je eroverheen kunt tekenen.

**Waarom een template?**

Een template wordt op een aparte laag geplaatst en dient als referentie. Hierdoor kun je de vogel overtrekken zonder de originele afbeelding steeds te selecteren.

## Stap 2: De vormen van de vogel maken

Begin met de grootste onderdelen van de vogel.

### Een rechthoek maken

1. Kies de Rectangle Tool.
2. Teken een rechthoek over het gewenste gedeelte van de vogel.
3. Stel de Fill in op None (transparant).
4. Geef de Stroke een opvallende kleur, bijvoorbeeld rood.

Zo zie je alleen de omlijning van de vorm.

### Anchor points aanpassen

Anchor points zijn de punten waarmee je de vorm van een object kunt aanpassen.

* Gebruik de Direct Selection Tool (witte pijl) om afzonderlijke punten te selecteren.
* Selecteer alleen de hoek die je wilt aanpassen.
* Houd Shift ingedrukt om meerdere anchor points te selecteren.
* Sleep de hoekrondjes naar binnen om afgeronde hoeken te maken.

Je kunt de rechthoek zo aanpassen totdat deze de gewenste vorm van de vogel heeft.

**Tip:** Selecteer eerst de juiste punten. Als je de volledige vorm geselecteerd hebt, pas je mogelijk alle hoeken tegelijk aan.

### Vormen samenvoegen

Wanneer je meerdere vormen hebt gemaakt:

1. Selecteer de vormen die je wilt samenvoegen.
2. Gebruik de Shape Builder Tool.
3. Sleep over de onderdelen die je wilt combineren.

Zo bouw je de vogel op uit afzonderlijke vormen.

# 3. Werken met cirkels en schalen

In deze oefening maak je de ogen en andere ronde onderdelen van de vogel.

## Een perfecte cirkel maken

1. Kies de Ellipse Tool.
2. Houd Shift ingedrukt terwijl je de cirkel tekent.
3. Je krijgt nu een perfecte cirkel in plaats van een ovaal.

## Een grotere cirkel maken

Je kunt een bestaande cirkel kopiëren en vergroten met Transform → Scale.

1. Selecteer de cirkel.
2. Klik met de rechtermuisknop.
3. Ga naar **Transform → Scale**.
4. Kies Uniform.
5. Vul het gewenste percentage in.
6. Klik op Copy.

**Belangrijk:** Klik op Copy in plaats van OK. Anders wordt de oorspronkelijke cirkel aangepast in plaats van dat er een nieuwe cirkel ontstaat.

### Schaalpercentages uit de les

| Onderdeel                       | Uniform percentage |
| ------------------------------- | -----------------: |
| Grotere cirkel                  |               174% |
| Eerste vergroting van het oog   |               200% |
| Volgende vergroting van het oog |               240% |

De percentages zijn voorbeelden uit de les. Pas ze aan op basis van de gewenste verhoudingen van jouw vogel.

### Voorbeeld: twee cirkels maken

1. Maak een perfecte cirkel.
2. Selecteer de cirkel.
3. Rechtermuisknop → Transform → Scale.
4. Vul 174% in bij Uniform.
5. Klik op Copy.

Je hebt nu twee cirkels.

Gebruik dezelfde methode om de ogen te maken, met de percentages 200% en 240% uit de les.

**Ongedaan maken:** Ctrl + Z.

## Objecten exact kopiëren

Je kunt een object ook kopiëren door het te verslepen.

* Houd Alt ingedrukt en sleep het object naar de gewenste plek.
* Er wordt een kopie gemaakt van het oorspronkelijke object.

Dit is handig voor de poten, ogen en andere onderdelen die hetzelfde moeten zijn.

Je kunt ook Ctrl + C en Ctrl + V gebruiken.

## De poten en onderkant tekenen

1. Maak een rechthoek voor één poot.
2. Maak een kopie met Alt + slepen.
3. Plaats de tweede poot.
4. Maak een nieuwe rechthoek voor de onderkant van de vogel.
5. Pas de hoeken aan met de anchor points en hoekrondjes.

Je hoeft niet altijd buiten de vorm te klikken voordat je de volgende hoek aanpast. Dit hangt af van welke tool en selectie je op dat moment gebruikt.

# 4. Vormen combineren en kleuren

Wanneer alle onderdelen van de vogel zijn gemaakt, kun je de vormen samenvoegen, kleuren en de volgorde aanpassen.

## De Shape Builder Tool gebruiken

De Shape Builder Tool is handig om overlappende vormen te combineren of delen te verwijderen.

### Vormen samenvoegen

1. Selecteer de vormen met de Selection Tool (zwarte pijl).
2. Kies de Shape Builder Tool.
3. Sleep over de onderdelen die je wilt samenvoegen.

### Onderdelen verwijderen

* Houd Alt ingedrukt terwijl je met de Shape Builder Tool op een onderdeel klikt.
* Hiermee kun je onderdelen verwijderen die je niet nodig hebt.

Je kunt ook met de tool over een gebied slepen om de gewenste delen te selecteren of samen te voegen.

**Tip:** Gebruik de Layers-panel om te controleren uit welke onderdelen de vogel bestaat.

## Fill-kleur aanpassen

Als je een vorm wilt inkleuren:

1. Selecteer de vorm.
2. Klik op Fill.
3. De Color Picker verschijnt.
4. Kies de gewenste kleur.
5. Klik op OK.

Herhaal dit voor alle onderdelen van de vogel.

Je kunt zelf de kleuren kiezen.

## De volgorde van objecten veranderen

Sommige onderdelen moeten voor of achter andere onderdelen staan.

Bijvoorbeeld: een oog moet boven op het gezicht liggen.

1. Selecteer het object.
2. Klik met de rechtermuisknop.
3. Kies **Arrange**.
4. Kies een van de volgende opties:

| Optie          | Betekenis                               |
| -------------- | --------------------------------------- |
| Bring to Front | Object helemaal naar voren brengen      |
| Bring Forward  | Object één niveau naar voren brengen    |
| Send Backward  | Object één niveau naar achteren brengen |
| Send to Back   | Object helemaal naar achteren brengen   |

Dit is handig als een vorm achter een andere vorm verdwijnt.

## De strokes verwijderen

Wanneer de vogel af is, kun je de rode omlijningen verwijderen.

1. Selecteer alle objecten met Ctrl + A.
2. Klik op de Stroke-instellingen.
3. Kies None (het witte vak met de rode diagonale streep).

Hiermee verwijder je de strokes en blijven de ingevulde kleuren over.

Let op: als je ook de Fill op None zet, verdwijnen de kleuren van de vormen.

## Het bestand opslaan

Sla het bestand op als:

`bird.ai`

Gebruik Ctrl + S en behoud de extensie .AI, zodat je het bestand later verder kunt bewerken.

# 5. Anchor points en de Pen Tool

De Pen Tool wordt gebruikt om vormen te tekenen en anchor points toe te voegen.

## Anchor points verwijderen

Achter de Pen Tool zitten verschillende verborgen tools.

Je kunt onder andere de Delete Anchor Point Tool gebruiken om punten te verwijderen die je niet nodig hebt.

### Waarom zo weinig mogelijk anchor points gebruiken?

* Minder anchor points maken vormen makkelijker te bewerken.
* Te veel punten kunnen onnodige knikken in een lijn veroorzaken.
* Met minder punten kun je vaak vloeiendere curves maken.

Gebruik dus alleen de anchor points die je nodig hebt om de gewenste vorm te maken.

# 6. Layers (lagen)

Layers gebruik je om verschillende onderdelen van een ontwerp apart te organiseren.

Bijvoorbeeld: een gezicht, ogen, neus en andere onderdelen op afzonderlijke lagen.

## Een bestaand Illustrator-bestand openen

Voor deze oefening gebruik je het bestand `boy.ai` uit de ZIP-map.

1. Pak de ZIP-map uit.
2. Open `boy.ai` in Illustrator.
3. Ga naar **Window → Layers** om het Layers-panel te openen.

Je ziet nu de verschillende lagen van het document.

## Waarom gebruiken we layers?

Met layers kun je:

* Onderdelen van een ontwerp afzonderlijk bewerken.
* Bepaalde objecten zichtbaar of onzichtbaar maken.
* Objecten vergrendelen zodat je ze niet per ongeluk aanpast.
* Onderdelen organiseren en overzichtelijk houden.

## Een nieuw gezicht op een aparte layer maken

1. Selecteer het gezicht in het bestaande document.
2. Kopieer het met Ctrl + C.
3. Open het Layers-panel.
4. Klik op het plusteken (+) om een nieuwe layer te maken.
5. Selecteer de nieuwe layer.
6. Plak het gezicht met Ctrl + V.
7. Maak het gezicht groter indien nodig.
8. Hernoem de layer door dubbel te klikken op de naam.
9. Noem de layer bijvoorbeeld `face`.
10. Druk op Enter.

Je hebt nu een aparte layer met het gezicht.

**Let op:** Controleer altijd welke layer actief is voordat je iets plakt of tekent.

## Layers vergrendelen

In het Layers-panel kun je een layer vergrendelen.

Dit voorkomt dat je de objecten op die laag per ongeluk verplaatst of aanpast.

Je kunt de zichtbaarheid van een layer ook aanpassen, zodat je bepaalde onderdelen tijdelijk kunt verbergen.

## Ogen en neus toevoegen

1. Maak een nieuwe layer met het plusteken (+).
2. Kopieer de ogen of neus.
3. Plak ze op de gewenste layer.
4. Verplaats de onderdelen naar de juiste positie.

Je kunt objecten ook rechtstreeks in het Layers-panel verplaatsen.

Als je een object sleept en een blauwe lijn ziet, geeft die lijn aan waar het object in de laagstructuur geplaatst kan worden.

### De volgorde van layers aanpassen

Wanneer een onderdeel achter een ander onderdeel zit:

1. Open het Layers-panel.
2. Sleep de layer omhoog of omlaag.
3. Controleer of het onderdeel nu voor of achter het juiste object staat.

Sla het bestand op als:

`boy.ai`

# 7. Werken met AI in Illustrator

In deze oefening gebruik je Adobe Illustrator AI-tools om extra objecten aan een bestaande illustratie toe te voegen.

Je werkt met het bestand `city_park.ai`.

## Stap 1: Het bestand openen

Je kunt het bestand op twee manieren openen:

* Dubbelklik op `city_park.ai`.
* Open Illustrator en kies File → Open.

## Stap 2: Een nieuw object toevoegen

Stel dat je een reuzenrad aan het stadspark wilt toevoegen.

1. Open het bestand `city_park.ai`.
2. Maak een nieuwe layer.
3. Teken een rechthoek op de plek waar het reuzenrad moet komen.
4. Pas de grootte van de rechthoek aan op de gewenste afmetingen.

## Stap 3: Generative AI gebruiken

1. Activeer de Contextual Task Bar.

2. Zoek de optie Generate Vectors.

3. Klik op Generate Vectors.

4. Typ een prompt, bijvoorbeeld:

   `Ferris wheel`

5. Je kunt eventueel een Style Reference gebruiken om de stijl van het gegenereerde object aan te passen.

De AI genereert vectorobjecten die je aan je illustratie kunt toevoegen.

Je kunt de gegenereerde objecten daarna verder aanpassen in Illustrator.

## Groeperen en ungroupen

Wanneer je meerdere objecten samen wilt houden, kun je ze groeperen.

### Groeperen

1. Selecteer de objecten.
2. Druk op Ctrl + G.

De objecten vormen nu één groep.

### Ungroupen

1. Selecteer de groep.
2. Klik met de rechtermuisknop.
3. Kies Ungroup.

Je kunt nu afzonderlijke onderdelen selecteren en aanpassen.

Als je een gegenereerd object niet nodig hebt, kun je het selecteren en verwijderen.

# 9. Onduidelijke punten uit de les

De volgende punten waren niet volledig duidelijk in de oorspronkelijke aantekeningen. Controleer ze eventueel op de slides, de Notion-website of bij de docent.

| Onderwerp                        | Wat nog onduidelijk is                                                                                                                                              |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ctrl + E                         | De precieze functie van deze sneltoets in de les is niet duidelijk.                                                                                                 |
| Alt + Shift bij vergroten        | Waarschijnlijk ging dit over proportioneel schalen of het aanpassen van de grootte vanuit een bepaald punt. De exacte handeling moet nog worden bevestigd.          |
| Command + C / Command + V        | Dit zijn Mac-sneltoetsen. Op Windows gebruik je Ctrl + C en Ctrl + V.                                                                                               |
| Transparantie via het vraagteken | De precieze tool of knop waarmee alle strokes verwijderd werden, is niet helemaal duidelijk. Gebruik de Stroke-optie en kies None om de omlijningen te verwijderen. |
| ZIP-bestanden                    | De notitie vermeldt dat bestanden in een ZIP kleiner worden. Je moet de ZIP eerst uitpakken om de bestanden normaal te kunnen gebruiken.                            |
| De onderste knop                 | De laatste aantekening “Click the bottom part” mist context. Controleer dit eventueel op de lesmateriaalpagina.                                                     |
